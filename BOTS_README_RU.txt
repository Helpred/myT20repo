TANKI 2.0 — BOT SYSTEM / RELEASE 19.0.0
=======================================

Боты являются полноценными участниками серверной BattleRoom.

Управление:
- выбрать созданную вами битву в лобби;
- нажать «+ ДОБАВИТЬ БОТА» или «− УБРАТЬ БОТА»;
- сервер оставляет как минимум одно место для живого игрока;
- программный лимит: до 16 ботов на одну битву, но также действует max_players комнаты.

Архитектура:
- Python server: HP, damage, kills, score, fund, kill limit, respawn, bot ownership;
- physics-host client: движение RigidBody3D, гусеницы, столкновения, визуальная стрельба;
- host migration: при выходе текущего host ботами начинает управлять другой живой клиент.

Боты являются врагами и для игроков, и друг для друга.
Релиз использует сетевой протокол v11.
