v20.0.2 — M0 visual fix

Причина артефактов v20.0.1:
1) добавленные remaster-детали использовали UV по всему старому M0-атласу, поэтому панели могли брать пиксели гусениц/темных деталей;
2) несколько накладок были почти копланарны старому корпусу и давали z-fighting;
3) normal map из старого lightmap была слишком сильной.

Исправлено:
- исходные вершины/UV старого Wasp M0 и Smoky M0 не меняются;
- только новые наращенные детали перенесены в безопасную чистую область атласа;
- накладки приподняты/вынесены наружу от исходных поверхностей;
- normal map ослаблена.

Установка:
python .\apply_v20_0_2_m0_visual_fix.py

После установки в Godot сделать Reimport для:
res://assets/hulls/wasp_m0_remaster.glb
res://assets/turrets/smoky_m0_remaster.glb
и перезапустить клиент.
