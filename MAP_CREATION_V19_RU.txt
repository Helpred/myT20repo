Tanki 19.1 — минимальные требования к пользовательской карте

ОБЯЗАТЕЛЬНО
1. Корень сцены: Node3D.
2. Хотя бы один Marker3D с точным именем Spawn_0.
3. Для текущего сетевого загрузчика карта должна оставаться производной Arena и
   ссылаться на res://assets/maps/arena/arena_visual_editor.gltf.
4. Файл .tscn должен быть UTF-8 и не больше 512 KiB.

СПАВНЫ
- Маркеры называются Spawn_0, Spawn_1, Spawn_2 ... без пропусков желательно.
- Клиент ищет до Spawn_63, то есть технический потолок редакторских маркеров — 64.
- Комната допускает максимум 32 участника.
- Сервер держит минимум 9 логических spawn-слотов для обратной совместимости.
- Если реальных маркеров меньше, создаются виртуальные боковые позиции вокруг них.
- Для нормальной игры с ботами рекомендуется 6–12 РЕАЛЬНЫХ точек; для большой
  комнаты — 9–16. Не ставьте spawn внутри стены, под низким потолком или на краю.
- Направление Marker3D задаёт направление корпуса при появлении.

ПРИПАСЫ
- Точки падения: Marker3D Supply_0, Supply_1, Supply_2 ...
- Жёсткого игрового лимита нет, но сервер читает все числовые Supply_N из .tscn.
- Если Supply_N отсутствуют на Arena-derived карте, используются старые 32 точки Arena.
- На сильно переделанной геометрии обязательно расставьте Supply_N вручную на
  открытых местах с достаточным пространством сверху.

РЕСУРСЫ/СКРИПТЫ
- Сейчас по сети передаётся только .tscn (и preview), не произвольный пакет ассетов.
- Пользовательские Script запрещены, кроме res://scripts/arena_editable_runtime.gd.
- Новые внешние модели/текстуры, которых нет в клиентском билде, не загрузятся.
