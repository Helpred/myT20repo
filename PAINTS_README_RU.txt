КРАСКИ / v15

Каталог:
  client/assets/paints/

Самый простой способ добавить краску:
  1. Положи туда seamless PNG/JPG/WebP, например desert.png
  2. Запусти Godot. Краска появится в меню автоматически.

Рекомендуемый размер: 512x512 или 1024x1024, квадратная seamless-текстура.

Опционально рядом можно положить desert.json:
{
  "name": "Desert",
  "scale": 2.55,
  "strength": 0.76
}

scale    — сколько раз рисунок повторяется на UV-атласе. Больше = мельче пятна.
strength — сила нанесения краски на paintable mask, обычно 0.65-0.85.

При добавлении новой краски файл должен присутствовать у всех клиентов, чтобы они
видели её одинаково. Сервер хранит/передаёт только paint id и не требует изменения.
