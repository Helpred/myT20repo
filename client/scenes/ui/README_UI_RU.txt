Если Godot пишет «дочерний узел контейнера», выбирай реальный элемент ВНУТРИ
узла с суффиксом Slot. Например: RankXPSlot -> RankXP. RankXP уже свободно
редактируется. Для полностью ручной раскладки можно перенести элемент в FreeCanvas.

Функциональные узлы теперь ищутся по имени рекурсивно, поэтому родителей менять
можно. Не переименовывай функциональный узел и не создавай дубликат с тем же именем.

Карты добавляются автоматически из res://scenes/maps/*.tscn.
