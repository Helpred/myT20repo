SERVER AUTHORITY v16.3

Теперь сервер является источником каталога корпусов, пушек, модификаций, боевых статов и красок.

Краски добавляются ТОЛЬКО на сервер:
  server/assets/paints/my_paint.png
  server/assets/paints/my_paint.json   (необязательно)

JSON пример:
{
  "name": "My Paint",
  "scale": 1.0,
  "strength": 0.86
}

Поддерживаются PNG/JPG/JPEG/WebP. После добавления краски перезапустите server.py.
Клиенты получают список красок при UDP handshake и сами скачивают текстуры по TCP HTTP с asset-port (по умолчанию 9101).
Для игры по сети должны быть доступны UDP 9100 и TCP 9101.

Пользовательская краска, положенная в клиент, больше не сканируется и не может быть выбрана сервером. Модифицированный клиент всё ещё может нарисовать себе что угодно локально, но canonical paint ID, который видят остальные игроки, проверяет сервер.

Боевые статы: server/data/combat_stats.json
Доступные корпуса/пушки/модификации: server/data/loadout_catalog.json
